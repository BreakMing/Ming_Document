## 为什么需要滤波器

在我们生活和工作中存在大量不确定性，主要包含以下三个方面。

 ```
 1、没有完美的模型（包括物理、噪声等）
 2、周边环境带来的不确定性
 3、测量传感器本身误差
 ```

滤波器正是为了解决这些问题而出现的，在众多滤波算法中，卡尔曼滤波是线性系统下理论最完备、工程应用最广泛的方案，

## 什么是卡尔曼滤波器

从多个不确定的数据中，经过分析、推理和计算，得到一个相对准确的结果。

数据可以是传感器的测量值，也可以是模型的估计值。

卡尔曼滤波器主要对噪音信号的过滤和去噪，它兼具滤波器和观测器的特性，在一些应用中主要对系统状态的估计和预测，也可被视为观测器，而它是最优化的、递归的数字处理算法。
