## 如何获取一个准确的值

在我们生活和工作中存在大量不确定性，主要包含以下三个方面。

 ```
 1、没有完美的模型（包括物理、噪声等）
 2、周边环境带来的不确定性
 3、测量传感器本身误差
 ```

滤波器正是为了解决这些问题而出现的，滑动平均等简单滤波方法难以兼顾响应速度与降噪效果，而卡尔曼滤波在线性系统与高斯噪声的假设下，能基于最小均方误差准则实现模型预测与观测数据的最优融合，同时凭借递推式计算结构保持极低的运算开销，无需存储大量历史数据即可实时运行，既能完成单路信号平滑去噪，也支持多传感器状态融合，是工程中兼顾精度与效率的优选方案。

在正式进入滤波器之前，我们先通过一个生活中最简单的例子，建立卡尔曼滤波的核心直觉。

## 什么是卡尔曼滤波器

从多个不确定的数据中，经过分析、推理和计算，得到一个相对准确的结果。数据可以是传感器的测量值，也可以是模型的估计值。

### 三大特性

```

```
递归性：卡尔曼滤波器不需要存储任何历史数据。
最优性（在线性系统 + 高斯噪声假设下）：卡尔曼滤波在数学上被证明是最小均方误差（MMSE）意义下的最优线性估计器。
滤波器 + 观测器：它既可以当作滤波器，对单路含噪信号进行平滑去噪；也可以当作观测器（状态观测器），从可测量的量中反推出不可直接测量的系统内部状态。

### 预测-更新循环（核心结构预览）

卡尔曼滤波的工作方式是一个不断重复的两阶段循环：

```
┌────────────┐         ┌────────────┐
│  预测阶段   │ ──────▶ │  更新阶段   │
│ (时间更新)  │ ◀────── │ (测量更新)  │
│            │         │            │
│ 用模型推算  │         │ 用测量修正  │
│ 下一拍状态  │         │ 预测的结果  │
└────────────┘         └─────┬──────┘
       ▲                     │
       │     新的测量值       │
       └─────────────────────┘
```

- **预测阶段（先验估计）**：利用系统的物理模型，根据上一拍的状态，推算出"如果没有任何测量，现在系统应该是什么状态"。同时也会推算"我对这个猜测有多不确定"。
- **更新阶段（后验估计）**：拿到传感器的实际测量值后，在预测值和测量值之间做一个最优的加权平均，得到当前拍的最终估计。谁的噪声小（可信度高），谁在加权中的比重就更大。

## 从一个生活例子理解卡尔曼滤波的核心思想

在正式接触公式之前，我们先通过一个简单到可以手算的例子，建立卡尔曼滤波的直觉。

### 问题场景：估计房间温度

假设你坐在房间里，想知道当前的准确温度，你有两个信息来源：

- **信息来源 A（模型预测）**：你认为房间温度不会突变，上一拍的最优温度估计是 $22^\circ C$，你对你这个模型的信心是 $\pm1^\circ C$（方差 = 1）。
- **信息来源 B（传感器测量）**：你有一个廉价温度计，它显示 $25^\circ C$，但你知道这个温度计不太准，精度大约是 $\pm3^\circ C$（方差 = 9）。

问题来了：真实的温度到底是多少？直觉上，因为温度计的误差更大（方差 9 >> 方差 1），我们应该**更相信模型**，所以真实温度应该离 $22^\circ C$ 更近，离 $25^\circ C$ 更远。

### 核心逻辑：加权平均

卡尔曼滤波的核心思想就是一句话：**谁更可靠，就相信谁更多**。

对于两个独立的信息来源（方差分别为 $\sigma_1^2$ 和 $\sigma_2^2$），它们的最优融合方式就是按各自**方差的倒数**作为权重，做加权平均：

$$x_{fused} = \frac{\sigma_B^2 \cdot x_A + \sigma_A^2 \cdot x_B}{\sigma_A^2 + \sigma_B^2}$$

代入我们的例子：

$$x_{fused} = \frac{9 \times 22 + 1 \times 25}{1 + 9} = \frac{198 + 25}{10} = 22.3^\circ C$$

融合结果 $22.3^\circ C$ 明显偏向更可信的模型预测值 $22^\circ C$，这就是卡尔曼滤波在做的事情。

### 融合后的不确定度

融合不仅给出最优估计值，还能告诉我们融合后的不确定度是多少。两个独立信息融合后的方差满足：

$$\frac{1}{\sigma_{fused}^2} = \frac{1}{\sigma_A^2} + \frac{1}{\sigma_B^2}$$

化简得：

$$\sigma_{fused}^2 = \frac{\sigma_A^2 \cdot \sigma_B^2}{\sigma_A^2 + \sigma_B^2} = \frac{1 \times 9}{1 + 9} = 0.9$$

融合后的方差 $0.9$ 比原来两个来源的方差（1 和 9）都小。**融合总是让你更确定**——这是卡尔曼滤波的一个重要性质。

### 递推的魅力：不需要历史数据

现在温度计的读数变了：第 2 秒，温度计显示 $24^\circ C$。你不需要重新翻出之前的所有数据，只需要：

- **上一拍的最优估计**：$22.3^\circ C$，方差 $0.9$
- **系统模型**：温度不会突变（但可能缓慢漂移），给模型加一点过程噪声，比如方差 $0.1$
- **当前测量**：$24^\circ C$，方差 $9$

**预测**：$x_{pred} = 22.3$，$\sigma_{pred}^2 = 0.9 + 0.1 = 1.0$

**融合**：$x_{fused} = \frac{9 \times 22.3 + 1 \times 24}{1 + 9} = 22.47^\circ C$

这就是卡尔曼滤波的**递推（Recursive）**本质：每一步只保留一个估计值和一个不确定度，绝不回头翻历史数据。对嵌入式系统来说，这意味着恒定的、极小的内存开销。

### 标量版伪代码（10行）

```
初始化:
    x = 25.0          // 初始温度估计（随便猜一个）
    p = 100.0         // 初始不确定度（很大，因为初始猜测不可靠）
    q = 0.01          // 过程噪声（模型认为温度变化很慢）
    r = 9.0           // 测量噪声（温度计不准）

每个测量周期:
    // 预测
    x_pred = x                        // 假设温度不变
    p_pred = p + q                    // 不确定度积累

    // 更新
    k = p_pred / (p_pred + r)        // 卡尔曼增益（权重分配）
    x = x_pred + k * (z - x_pred)    // 融合测量值 z
    p = (1.0 - k) * p_pred           // 更新不确定度
```

你可以手动推演几轮试试：哪怕初始猜测 $x=25.0$ 是随便设的，经过几轮迭代后，估计值会稳定收敛到真实温度附近。

## 卡尔曼滤波的五个公式：它们在做什么

房间温度的例子中只有一个变量（温度），所以所有公式都是标量运算。真实世界中，我们往往需要同时估计多个状态（比如角度 + 角速度零偏），这时就需要用**矩阵**来表达了。卡尔曼滤波的全部计算，就浓缩在以下五个公式中。

### 全景图：预测-更新两阶段

| 阶段 | 编号 | 公式 | 作用 |
|:---:|:---:|:------|:------|
| 预测 | (1) | $\hat{x}_k^- = F\hat{x}_{k-1} + Bu_k$ | 用模型推算当前状态 |
| 预测 | (2) | $P_k^- = FP_{k-1}F^T + Q$ | 推算当前不确定度 |
| 更新 | (3) | $K_k = P_k^-H^T(HP_k^-H^T + R)^{-1}$ | 计算最优权重（卡尔曼增益） |
| 更新 | (4) | $\hat{x}_k = \hat{x}_k^- + K_k(z_k - H\hat{x}_k^-)$ | 用测量值修正预测 |
| 更新 | (5) | $P_k = (I - K_kH)P_k^-$ | 更新融合后的不确定度 |

> 符号约定：带 $-$ 上标的是**先验**（预测值，还没用测量修正），不带的是**后验**（最终输出）。$F$ 是状态转移矩阵，$H$ 是测量矩阵，$Q$ 是过程噪声协方差，$R$ 是测量噪声协方差。

### 逐条白话讲解

#### 预测公式 (1)：$\hat{x}_k^- = F\hat{x}_{k-1} + Bu_k$

**它在做什么：推算"现在应该是多少"。**

用上一拍的最优估计 $\hat{x}_{k-1}$，乘以系统的运动规律 $F$，得到当前拍的预测值。如果有已知的外部输入 $u_k$（比如电机控制量），也通过 $B$ 矩阵加入。

打个比方：你上一秒在 $x=10$ 的位置，以 $v=2\ m/s$ 的速度前进。如果没有任何传感器告诉你别的信息，你只能靠 $x_{now} = 10 + 2 \times 1 = 12$ 来猜现在的位置。这里的 $F$ 矩阵就是在表达 $x+v\cdot dt$ 这个物理关系。

#### 预测公式 (2)：$P_k^- = FP_{k-1}F^T + Q$

**它在做什么：推算"现在有多不确定"。**

$P$ 是协方差矩阵，它描述了状态估计的**不确定度**。$P$ 的对角线元素是各状态自身的方差，非对角线元素是状态之间的关联不确定性。

这个公式做了两件事：
1. $FP_{k-1}F^T$：把上一拍的不确定度也用 $F$ 矩阵传播到当前拍（不确定度也遵循系统的运动规律）
2. $+Q$：额外加上过程噪声——你对模型越不自信，$Q$ 就设得越大

#### 更新公式 (3)：$K_k = P_k^-H^T(HP_k^-H^T + R)^{-1}$

**它在做什么：计算卡尔曼增益——"这次该信模型多一点，还是信传感器多一点"。**

这是整个卡尔曼滤波器的**心脏**。$K$（卡尔曼增益）是一个比例因子，它在算：

$$K \approx \frac{预测的不确定度}{预测的不确定度 + 测量噪声}$$

- 如果测量噪声 $R$ 很大（传感器不可信） → $K$ 很小 → 几乎忽略测量值，只相信模型预测
- 如果预测不确定度 $P_k^-$ 很大（模型不可信） → $K$ 接近 1 → 几乎完全采用测量值
- 如果两者相当 → $K \approx 0.5$ → 各取一半

$K$ 是**动态变化**的——随着滤波器不断运行，$P$ 会慢慢减小（你越来越确定），$K$ 也会随之变小。

#### 更新公式 (4)：$\hat{x}_k = \hat{x}_k^- + K_k(z_k - H\hat{x}_k^-)$

**它在做什么：用测量值修正预测，输出最优估计。**

括号里的 $z_k - H\hat{x}_k^-$ 叫做**新息（Innovation）**或**测量残差**——测量值和你预测的值之间差了多少。

如果测量值和预测值完全一致，新息 = 0，状态不会被修正；如果差异很大，$K$ 决定这个差异中有多少比例被"加回"到预测值上。

这个公式本质上就是在做 $x_{final} = x_{pred} + weight \times (z - x_{pred})$，和房间温度例子里的加权平均是一模一样的逻辑。

#### 更新公式 (5)：$P_k = (I - K_kH)P_k^-$

**它在做什么：更新融合后的不确定度。**

融合之后，你的不确定度一定会**下降**（因为融合了两个信息源）。降多少取决于 $K$：如果 $K$ 很大（你非常相信测量），不确定度就大幅下降；如果 $K$ 接近于零（你几乎不相信测量），不确定度几乎没有变化。

### 五个公式输入输出汇总

| 公式 | 输入 | 输出 | 通俗理解 |
|:---:|:------|:------|:------|
| (1) | 上一拍状态 $\hat{x}_{k-1}$、控制输入 $u_k$ | 预测状态 $\hat{x}_k^-$ | "推算现在应该是多少" |
| (2) | 上一拍不确定度 $P_{k-1}$、过程噪声 $Q$ | 预测不确定度 $P_k^-$ | "推算现在有多不确定" |
| (3) | 预测不确定度 $P_k^-$、测量噪声 $R$ | 卡尔曼增益 $K_k$ | "算出这次该信谁" |
| (4) | 预测状态 $\hat{x}_k^-$、测量值 $z_k$、增益 $K_k$ | 最优估计 $\hat{x}_k$ | "按最优比例修正" |
| (5) | 预测不确定度 $P_k^-$、增益 $K_k$ | 更新后不确定度 $P_k$ | "修正后还剩多少不确定" |

## 工程实例：用卡尔曼滤波融合加速度计和陀螺仪估计角度

这是我们最熟悉的场景：手上有一块 MPU6050，我们希望实时获取载体的俯仰角。

### 问题定义

- **陀螺仪**：测量角速度 $\omega$（°/s），积分可得角度。短期精度高，但零偏会随时间累积导致角度无限漂移。
- **加速度计**：通过重力分量反正切可得角度 $\theta_{acc} = \arctan(a_y, a_z)$。长期无漂移，但受振动影响大，瞬时噪声严重。

我们的目标：用卡尔曼滤波融合二者，取陀螺仪的**短期高精度** + 加速度计的**长期无漂移**，得到最优角度估计。

### 建立系统模型

#### 状态向量：我们要估计什么

$$x = \begin{bmatrix} \theta \\ b \end{bmatrix}$$

- $\theta$：载体的真实俯仰角（我们想要的）
- $b$：陀螺仪的零偏（我们顺便估计出来的，用来补偿陀螺仪原始数据）

为什么要估计零偏？因为陀螺仪零偏不是恒定的——它会随温度、时间缓慢变化。如果能在线实时估计出零偏，就可以从前端消除漂移的来源，比被动地用加速度计"拉回来"更优雅。

#### 状态转移方程（预测模型）

物理规律很直接：

- 角度的变化 = 角速度 × 时间（注意减去零偏）
- 零偏变化极慢，近似为常量（只加一点点噪声表示它允许缓慢漂移）

$$\theta_k = \theta_{k-1} + (\omega_k - b_{k-1}) \cdot \Delta t$$

$$b_k = b_{k-1}$$

写成矩阵形式：

$$\begin{bmatrix} \theta_k \\ b_k \end{bmatrix} = \begin{bmatrix} 1 & -\Delta t \\ 0 & 1 \end{bmatrix} \begin{bmatrix} \theta_{k-1} \\ b_{k-1} \end{bmatrix} + \begin{bmatrix} \Delta t \\ 0 \end{bmatrix} \omega_k$$

所以状态转移矩阵 $F$ 和控制矩阵 $B$ 为：

$$F = \begin{bmatrix} 1 & -\Delta t \\ 0 & 1 \end{bmatrix}, \quad B = \begin{bmatrix} \Delta t \\ 0 \end{bmatrix}$$

> 注意：这里的 $\omega_k$ 是**陀螺仪直接输出的角速度**。它在数学上是"控制输入"的角色——告诉系统这一拍旋转了多少。

#### 测量方程（观测模型）

加速度计可以测量重力方向，从而反算出角度：

$$\theta_{acc} = \theta_k + v_k$$

其中 $v_k$ 是测量噪声（振动、加速度计自身噪声等）。写成矩阵形式：

$$z_k = \begin{bmatrix} 1 & 0 \end{bmatrix} \begin{bmatrix} \theta_k \\ b_k \end{bmatrix} + v_k$$

所以测量矩阵 $H$ 为：

$$H = \begin{bmatrix} 1 & 0 \end{bmatrix}$$

这个 $H$ 的含义是：**我们只能直接测量角度 $\theta$，不能直接测量零偏 $b$**。$b$ 的估计完全靠滤波器自己"推理"出来。

### 参数初始化

| 参数 | 符号 | 物理含义 | 如何设定 |
|:---:|:---:|:------|:------|
| 初始状态 | $\hat{x}_0$ | 第一次启动时对角度和零偏的猜测 | 角度可以取加速度计反算的初始值；零偏初始设为 0 |
| 初始协方差 | $P_0$ | 对初始猜测的自信程度 | 设大一点（如 diag(1, 1)），让滤波器自己快速收敛 |
| 过程噪声 | $Q$ | 模型本身的不完美程度 | 对角阵 diag($q_\theta$, $q_b$)。$q_\theta$ 反映模型对角度预测的误差（如未建模的动态），$q_b$ 反映零偏的变化速率 |
| 测量噪声 | $R$ | 加速度计角度测量的噪声水平 | 将传感器静置，取 200~500 个采样点算加速度计角度的方差即可得到 R 的合理估计 |

### 完整伪代码（矩阵展开为标量运算）

```
初始化:
    dt = 0.01                            // 采样周期 (s)，假设 100Hz
    gyro = 0.0                           // 当前陀螺仪读数
    accel_angle = 0.0                    // 加速度计推算角度

    // ---- 状态向量 x = [角度, 零偏] ----
    angle = 0.0                          // 初始角度估计
    bias = 0.0                           // 初始零偏估计

    // ---- 协方差矩阵 P（不确定度） ----
    // P = [[p00, p01], [p10, p11]]
    p00 = 1.0                            // 角度估计的方差（初始不确定，设大些）
    p01 = 0.0
    p10 = 0.0
    p11 = 1.0                            // 零偏估计的方差

    // ---- 过程噪声协方差 Q（对模型的信任度） ----
    q_angle  = 0.001                     // 角度模型噪声
    q_bias   = 0.000003                  // 零偏漂移噪声（极慢，所以非常小）

    // ---- 测量噪声 R（对加速度计角度测量的信任度） ----
    r_measure = 0.03                     // 通过静止测量获得


每个采样周期循环:

    // ============ 0. 读取传感器原始数据 ============
    gyro_rate   = read_gyroscope()       // 陀螺仪角速度 (rad/s)
    accel_angle = read_accel_angle()     // 加速度计推算角度 (rad)


    // ============ 1. 预测阶段（时间更新） ============

    // 状态预测: x_pred = F * x + B * gyro_rate
    // F = [[1, -dt], [0, 1]]    B = [[dt], [0]]
    angle_pred = angle + (gyro_rate - bias) * dt
    bias_pred  = bias

    // 协方差预测: P_pred = F * P * F^T + Q
    // 将矩阵乘法展开为标量运算：
    // F*P:
    //   fp00 = 1*p00 + (-dt)*p10 = p00 - dt*p10
    //   fp01 = 1*p01 + (-dt)*p11 = p01 - dt*p11
    //   fp10 = 0*p00 + 1*p10     = p10
    //   fp11 = 0*p01 + 1*p11     = p11
    //
    // (F*P)*F^T:
    //   p00_pred_temp = fp00*1 + fp01*(-dt) = fp00 - dt*fp01
    //   p01_pred_temp = fp00*0 + fp01*1     = fp01
    //   p10_pred_temp = fp10*1 + fp11*(-dt) = fp10 - dt*fp11
    //   p11_pred_temp = fp10*0 + fp11*1     = fp11
    //
    // 再加 Q:
    p00_pred = p00 - dt*p10 - dt*(p01 - dt*p11) + q_angle
    p01_pred = p01 - dt*p11
    p10_pred = p10 - dt*p11
    p11_pred = p11 + q_bias


    // ============ 2. 更新阶段（测量更新） ============

    // 新息（预测角度与测量角度的偏差）
    // y = z - H*x_pred,  H = [1, 0]
    innovation = accel_angle - angle_pred

    // 新息协方差: S = H * P_pred * H^T + R
    // H*P_pred = [1*p00_pred + 0*p10_pred, 1*p01_pred + 0*p11_pred]
    //          = [p00_pred, p01_pred]
    // (H*P_pred)*H^T = p00_pred*1 + p01_pred*0 = p00_pred
    s = p00_pred + r_measure

    // 卡尔曼增益: K = P_pred * H^T / S
    // P_pred * H^T = [[p00_pred], [p10_pred]]
    // K = [[p00_pred / S], [p10_pred / S]]
    k0 = p00_pred / s                    // 角度修正增益
    k1 = p10_pred / s                    // 零偏修正增益

    // 状态更新: x = x_pred + K * innovation
    // [[angle], [bias]] = [[angle_pred], [bias_pred]]
    //                     + [[k0], [k1]] * innovation
    angle = angle_pred + k0 * innovation
    bias  = bias_pred  + k1 * innovation

    // 协方差更新: P = (I - K*H) * P_pred
    // I - K*H = [[1, 0], [0, 1]] - [[k0, 0], [k1, 0]]
    //         = [[1-k0, 0], [-k1, 1]]
    // P = (I-K*H) * P_pred:
    p00 = (1.0 - k0) * p00_pred
    p01 = (1.0 - k0) * p01_pred
    p10 = p10_pred - k1 * p00_pred
    p11 = p11_pred - k1 * p01_pred


    // ============ 3. 输出 ============
    output_angle = angle                 // 卡尔曼滤波融合后的最优角度
    output_bias  = bias                  // 实时估计的陀螺仪零偏
    output_rate  = gyro_rate - bias      // 零偏补偿后的角速度（可用作角速度环输入）
```

### 效果对比

| 方法 | 短期精度 | 长期漂移 | 抗振动 | 动态响应 | 计算量 |
|:------|:------:|:------:|:------:|:------:|:------:|
| 纯陀螺仪积分 | 高 | 严重漂移（几秒就开始偏） | 好 | 快 | 极低 |
| 纯加速度计 | 差（振动噪声大） | 无漂移 | 差 | - | 极低 |
| 卡尔曼滤波融合 | 高 | 无漂移 | 好 | 快 | 低 |

纯陀螺仪积分的问题在于：哪怕静止状态，零偏（比如 0.1°/s）也会在 10 秒内累积出 1° 的误差，1 分钟内就是 6°。卡尔曼滤波通过在更新阶段利用加速度计的长期无漂移特性，持续修正这个累积误差，同时在预测阶段保留陀螺仪的瞬时响应能力，实现了两者的最优结合。

## 调参指南

调参是卡尔曼滤波实践中最关键也最让人头疼的环节。好在，真正需要调的参数只有两个：**$Q$（过程噪声协方差）**和**$R$（测量噪声协方差）**。

### Q：你对模型的信任度（过程噪声协方差）

$Q$ 反映的是你的**系统模型本身有多不完美**。

- $Q$ 大 → "我不太相信模型能准确预测" → 滤波器会更依赖测量值，响应更快，但噪声也会更多地通过
- $Q$ 小 → "我非常相信模型" → 滤波器会忽略测量中的瞬时波动，输出很平滑，但对真实变化的响应很慢

在角度估计的例子中：

$$Q = \begin{bmatrix} q_\theta & 0 \\ 0 & q_{bias} \end{bmatrix}$$

- **$q_\theta$**：角度模型的过程噪声。设大一点（如 $0.1$），模型会认为角度变化不只是 gyro*dt，还有未知扰动，因此更愿意接受测量值的"纠正"。
- **$q_{bias}$**：零偏漂移的速率。零偏变化非常慢，所以这个值通常极小（如 $0.000001$）。你甚至可以把它设为 $0$，但设一个极小的非零值可以让滤波器在零偏确实变化时缓慢跟上。

### R：你对传感器的信任度（测量噪声协方差）

$R$ 反映的是你的**传感器测量值有多大的噪声**。

$R$ 是最容易确定的参数——把传感器静置，采集 200~500 个数据点，直接计算方差即可。这是一个客观值，不是"调"出来的。

### 黄金法则：Q/R 的比值才是关键

滤波器的行为几乎完全由 **$Q/R$ 的比值**决定，$Q$ 和 $R$ 的绝对值主要影响收敛速度（绝对值越大，收敛越快，但稳态波动也越大）。

|  | $R$ 小（传感器可信） | $R$ 大（传感器不可信） |
|:---:|:---|:---|
| **$Q$ 小（模型可信）** | 响应较快，输出平滑<br>★ **大多数场景的推荐起点** | 响应极慢，极度平滑<br>只信任模型，几乎忽略测量 |
| **$Q$ 大（模型不可信）** | 响应最快，但噪声通过率高<br>适合高速剧烈运动的系统 | 滤波基本不工作<br>两者都不信，估计质量差<br>⚠️ 应避免 |

### 实操调参步骤

1. **先定 $R$**：静置传感器，统计加速度计角度的方差，填入 $R$。这是唯一有客观依据的参数。
2. **$R$ 不变，调 $Q$**：从小往大调。观察输出角度——如果响应太慢（跟不上真实运动），加大 $Q$；如果噪声太大，减小 $Q$。
3. **确认收敛**：上电后观察前几秒，滤波器应该快速从初始猜测收敛到真实值。收敛慢说明 $Q$ 太小或 $P_0$ 太小。
4. **检查稳态**：静置时输出角度应该稳定在一个小范围内波动（比如 ±0.1°），不应该有可见的漂移。

## 常见问题与误区

### 为什么我的滤波器不收敛？

可能原因按排查顺序：

1. **系统模型（$F$ 或 $H$）写错了**：最常见的问题。检查状态转移方程是否真实反映了物理系统，特别是符号和单位。（比如 $dt$ 的单位是秒还是毫秒？角度单位是度还是弧度？）
2. **$Q$ 和 $R$ 的相对比例严重失调**：如果 $Q$ 极大而 $R$ 极小，滤波器会完全跟随测量值，看似"不收敛"其实是在跟踪噪声。
3. **状态不可观**：你想估计的状态（如零偏），是否可以通过测量值间接"看到"？如果 $H$ 矩阵无法反映某些状态对测量的影响，那些状态就不会收敛。
4. **$P$ 矩阵过早变小**：如果 $P_0$ 设得太小，滤波器从一开始就"过于自信"，拒绝接受新的测量信息来修正。

### 为什么估计值总是滞后于真实值？

这是卡尔曼滤波最常见的抱怨。原因通常是 **$Q$ 太小**或 **$R$ 太大**——滤波器过度信任模型，所以当状态发生真实变化时，滤波器认为"这应该是噪声"而拒绝快速跟上。

解决方法：加大 $Q$（特别是模型对应动态变化的分量）。在角度估计的例子中，如果你的载体在做快速的俯仰运动，需要适当增大 $q_\theta$。

### 协方差矩阵 P 会跑到奇怪的地方

- **$P$ 爆炸（越来越大）**：通常是因为 $Q$ 太大。每一步预测都在大量增加不确定度，测量更新来不及降回来。减小 $Q$。
- **$P$ → 0（趋于零）**：卡尔曼增益 $K$ 也会随之趋于零，滤波器会"锁死"不再更新。这通常意味着 $Q$ 太小且 $R$ 也有问题。确保 $Q$ 不要太小。
- **$P$ 不对称或出现负值**：这是数值精度问题。标准的协方差更新公式 $P = (I-KH)P^-$ 在浮点精度有限的嵌入式平台上可能丢失对称性。如果遇到，可以考虑 Joseph 形式（数值更稳定）：

$$P_k = (I - K_kH)P_k^-(I - K_kH)^T + K_k R K_k^T$$

或者在计算后手动强制对称：$P = (P + P^T)/2$。

### 模型不匹配时会发生什么？

卡尔曼滤波假设系统是**线性的**且噪声是**高斯的**。当真实系统违背这些假设时：

- **非线性系统**（比如用欧拉角做全姿态估计时，三角函数让系统变成强非线性）：标准 KF 的性能会严重下降甚至发散。此时需要用扩展卡尔曼滤波（EKF）或无迹卡尔曼滤波（UKF）——不过这超出了本文的范围，可以作为进一步学习的方向。
- **非高斯噪声**（比如传感器偶尔产生大的尖峰脉冲）：KF 会被这些离群值带偏。可以在更新前加一个"新息门限检测"：如果新息大于某个阈值（比如 3 倍标准差），就跳过这次更新，或者降权处理。

## 与其他滤波/融合算法的关系

在你已经了解的几种姿态估计算法中，卡尔曼滤波处于什么位置？下表给出直观对比：

|  | 一阶互补滤波 | Mahony 滤波器 | 卡尔曼滤波 |
|:---|:---:|:---:|:---:|
| **核心思想** | 高通 + 低通互补 | PI 控制器修正 + 四元数更新 | 模型预测与测量的最优加权 |
| **可调参数** | 1 个（滤波系数 $\alpha$） | 2 个（PI 的 $K_p, K_i$） | 2 个矩阵（$Q, R$），各自可能含多个元素 |
| **零偏估计** | ✗ 不估计 | ✓ PI 积分项在线估计 | ✓ 作为状态变量在线估计（更系统化） |
| **万向锁** | 取决于角度表示方法 | ✓ 使用四元数，无万向锁 | 取决于状态表示（本文示例是 1D 角度所以不涉及） |
| **理论最优性** | ✗ 经验方法 | ✗ 经验方法 | ✓ 在线性+高斯假设下理论最优 |
| **计算量** | 极小 | 小 | 小~中等（取决于状态维度） |
| **调参难度** | 极低 | 低~中 | 中（需要理解 Q/R 的物理含义） |
| **适用场景** | 简单平衡、粗略姿态 | 多数姿态估计，含零偏估计 | 噪声特性已知、追求最优精度 |

### 卡尔曼滤波的定位

> 关于一阶互补滤波和 Mahony 滤波器的详细原理与实现，可参考 [[Gyroscope]]。

简单来说：
- 刚入门、做平衡车、简单姿态显示 → **一阶互补滤波**，一个参数调好就够用
- 需要解决陀螺仪零偏漂移、有一定精度要求 → **Mahony 滤波器**，PI 控制器直观好调
- 你知道传感器噪声特性、想要理论最优的精度、或者需要同时估计多个相互关联的状态 → **卡尔曼滤波**

三者不是替代关系，而是递进关系。在实际项目中，选择哪一种取决于你对精度、复杂度和调试时间之间的权衡。
